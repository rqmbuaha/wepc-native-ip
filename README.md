## 原生IP、双ISP住宅IP、机房IP，在 TikTok 眼里是三样东西

普通数据中心的 IP，ASN 归属写着机房，平台识别成本很低。常见的表现是新账号注册就触发验证、视频冷启动流量接近 0、直播间被限制观看人数，严重的直接封号。这是 IP 属性问题，跟你发的内容质量没关系。

原生 IP 指的是这个地址由当地运营商分配、归属地真实，并且在平台的滥用数据库里没有留下记录。WePC 宣传里把它叫做“没被滥用过的处女 IP”，说法有点营销味，但方向是对的：IP 的历史干净，平台给的初始信任度就高。

双 ISP 住宅 IP 更进一步。同一个 IP 上挂了两个运营商的路由，注册信息表现为住宅宽带用户，同时线路质量比纯家宽稳定。做直播的人更在意这个组合，纯住宅 IP 归属真实但线路容易抖，纯商业线路稳定但容易被识别。

有个细节得先提醒。**同一台机房，不同测评给的 IP 标签是对不上的**。新加坡节点，一篇标“原生IP”，另一篇标“双ISP住宅IP”，第三篇又标回“原生IP”；德国和英国也是一样，三篇文章三种说法。这些标签都是测评作者自己贴的，不是官网 SKU 名称。真要在意，下单前看购物车或产品页上那行 IP 说明，别信二手转述。

## 线路怎么选，比 IP 标签更影响实际体验

TikTok 直播卡不卡，一半看 IP，一半看回程线路。

**香港**走 CMI 直连或 AS4837，标称 300Mbps 到 500Mbps 大带宽，达量限速不停机。适合建站和需要大带宽的场景，做 TikTok 的话香港不算主流市场。

**日本**用 IIJ 线路，三网直连，测评里国内访问延迟 40 到 80ms。这是亚洲区做直播最省事的选项，不用额外买中转。

**澳大利亚**移动和联通访问快，延迟 80 到 120ms，电信会绕美国，延迟明显高一截。三篇测评在这一点上说法完全一致，电信用户慎选。

**美国洛杉矶**分两种走法。4837 是常规优化，9929 回程更好，官网写“直播无需中转”的那两档就是 9929。延迟参考值 150ms 上下，做直播够用，做实时互动会有一点感。

东南亚和欧洲多数节点国内直连不理想，官方自己也标了“需中转”。中转服务要另外买，这笔钱得算进去。

## 标价不等于到手价，这几条最容易踩

**计价货币是澳元。** 三个来源给的汇率分别是 1:4.8、1:4.6、1:4.5–5，取中间值，1 澳元大约 4.5 到 4.8 元人民币。12.90 澳元折人民币 58 到 62 元，用九折码后 52 到 56 元。

**流量双向计算。** 标 1TB 是上传加下载合计，不是单向。

**超流量限速，不停机。** 官网美国页面写限速 3M，测评文章写 5Mbps 或 10Mbps。限速后能继续跑，不额外收费，但直播基本没法看了。

**换 IP 要钱。** 这条写在服务条款里，很少有人在测评里提：换一次 IPv4 收 5 澳元，每台 VPS 每月最多换两次。换完 24 小时内仍被封，可以提工单申请人工再换一次；超过 24 小时就视为更换完成。

**转移要钱。** 换机房收 2.5 澳元一次，月付产品剩余时长不足 15 天不能转。

**有些套餐明确不退款。** 条款里点名 HK_3CMI 系列不退款。

**使用限制比想象中严。** 禁止 BT、迅雷、公开代理、流量挖矿、CDN、PT、嵌套虚拟化；美国节点页面还单独写了一行“严禁使用 shadowsocks 协议”。买之前确认你的用途不在这张清单上，违规是直接终止不退款。

**热门机房会断货。** 香港和日本偶尔缺货，急着用的话先选其它节点。

**PayPal 只支持澳币结算**，账户币种不是澳元会有汇率损失。
